# Cyber Threat Analytics Platform with Incident Visualization System

## 🚀 Project Overview

This project was completed as part of my internship with **Infosys Springboard Virtual Internship 7.0**.

**Cyber Threat Analytics Platform with Incident Visualization** is an interactive Business Intelligence and cybersecurity analytics project designed to analyze global cybersecurity incidents and transform raw cybersecurity data into meaningful insights through interactive dashboards.

The project uses **Microsoft Power BI, Power Query, and DAX** to transform the **Global Cybersecurity Threats (2015–2024)** dataset into meaningful insights and an easy-to-understand visual experience.

The project demonstrates how Business Intelligence and data visualization can be used to analyze real-world cybersecurity problems by providing:

* 📊 Data-driven insights
* 📈 Interactive visualizations
* 🔍 Meaningful cybersecurity analysis
* ⚠️ Risk and financial impact analysis
* 🌍 Global cybersecurity trend analysis

## 🚀 Key Features

📊 **Interactive Cybersecurity Dashboards**

* Provides seven interactive Power BI dashboards for analyzing cybersecurity incidents from different perspectives.
* Uses KPIs, charts, maps, tables, and slicers for interactive analysis.

🔍 **Cyber Attack Analysis**

* Analyzes different attack types and attack sources.
* Identifies cybersecurity trends across years.
* Analyzes incidents based on countries, industries, and risk levels.

🧠 **Vulnerability & Defense Analysis**

* Analyzes major cybersecurity vulnerabilities.
* Examines the distribution of defense mechanisms.
* Helps understand the relationship between vulnerabilities and security measures.

⚙️ **Risk & Financial Impact Analysis**

* Examines high-risk cybersecurity incidents.
* Analyzes financial losses caused by cyber attacks.
* Studies affected users and incident resolution time.
* Provides insights into the overall impact of cybersecurity threats.

📈 **Pattern & Trend Analysis**

* Identifies cybersecurity patterns across different years.
* Analyzes trends based on countries and attack types.
* Examines changes in risk levels and cybersecurity incidents.

## 📊 Project Workflow

**Data Collection**

* Collected the **Global Cybersecurity Threats (2015–2024)** dataset from Kaggle.
* Studied the available cybersecurity attributes and variables.

**Data Cleaning & Preprocessing**

* Cleaned and transformed the dataset using Power Query.
* Removed duplicate records.
* Corrected data types and inconsistencies.
* Standardized values and categories.
* Prepared the dataset for analysis and visualization.

**Data Analysis**

* Analyzed cybersecurity incidents based on:

  * Attack type
  * Attack source
  * Country
  * Industry
  * Vulnerability
  * Risk level
  * Financial loss
  * Affected users
  * Resolution time
  * Defense mechanisms

**Visualization / Development**

* Developed seven interactive Power BI dashboards.
* Used different visualization techniques, including:

  * KPI cards
  * Bar charts
  * Line charts
  * Donut charts
  * Treemaps
  * Maps
  * Tables
  * Slicers

**Insights & Interpretation**

* Analyzed the dashboards to identify:

  * Important cybersecurity patterns
  * Risk levels
  * Financial impacts
  * Major vulnerabilities
  * Defense mechanisms
  * Attack trends
  * Country-wise cybersecurity patterns
